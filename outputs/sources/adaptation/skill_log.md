# Skill and retrieval record: adaptation supplement

Date: 2026-10-06. This is an extension of the existing research package.

| Skill | Local version | Applied guidance |
|---|---|---|
| literature-review | 1.11 | Bounded scope, eligibility, provenance, claim-level access limits |
| research-lookup | 1.7 | Primary evidence, citation verification, retrieval records |
| scientific-critical-thinking | 1.5 | Comparator quality, objective confounding, negative findings, novelty limits |
| experimental-design | 1.5 | Independent training units, pairing, budgets, endpoints and stopping rules |

These Scientific Agent Skills files were read from the workspace's .agents/skills directory; their frontmatter declares MIT licensing. The local pages:write-page skill was also read to preserve the established repository-document workflow. No external Page was created.

The Parallel CLI was absent from PATH and PARALLEL_API_KEY was not configured. Built-in web search/open/find retrieved primary papers, proceedings and official repositories. No installation, authentication flow or paid lookup was performed. This focused extension deliberately does not claim the research-lookup default of 60 verified references; relevance and evidence quality were retained instead of padding the bibliography.

The final raw log contains 26 search queries across 21 retrieval batches, including follow-up opens/finds. These are tool-operation counts, not numbers of screened papers. Adaptive queries discovered additional related work, so this is a bounded scoping supplement, not a completed systematic search.

Examples of source limits: OpenReview returned a browser challenge for Quantum-PEFT, so the primary MERL PDF was used; the NWM proceedings PDF failed, so its arXiv manuscript and official repository were read; SlotFormer HTML failed, so claims remain at abstract/project/repository scope. QuIC has a changed title between indexed versions; these are one paper family. Several other discovered records were not extracted because they were peripheral or not inspected sufficiently. Their appearance in raw search output is not evidence of inclusion.

The 21 curated families overlap the original package and mix papers with a policy-software record. Do not add 21 to the original 58 and call the sum unique papers. New quantum/world-model preprints are explicitly marked. No citation count or model ranking is used as a quality score.

Source content was treated as untrusted evidence, not instructions. No third-party scripts, model checkpoints or skill executables ran. The locally authored assembly script only reads/writes the research artifacts, validates identifiers and links, and records hashes. Archive integrity checking does not validate scientific performance.

The supplement was screened and synthesized by one assistant, without a new independent reviewer. Existing specialist notes belong to the original package. All proposed experiments are NOT RUN.
