# Prospective literature-review protocol v1

Recorded locally on 2026-10-06 before scientific literature retrieval. This is a local timestamped protocol, not a public registry submission. Amendments must be appended, not silently described as preregistered. Scope and output list follow the user-supplied master prompt (archived under audit).

Question: For navigation with multimodal, correlated, partially observed obstacle futures, what representational differences of density operators (QLC), locally purified object-slot tensor networks (PSC), or persistent projective branches (TEC) survive strong classical comparisons and justify falsifiable tests?

Coverage: 2021 through 2026-10-06 for applications, any year for foundational mathematics, tracking, planning and scoring. English-accessible primary reports. Search complementary arXiv, official proceedings (PMLR/OpenReview/CVF/RSS), publisher records, author-hosted full papers, and official software documentation. Ranked public web discovery is supplementary and must be labeled as such. Where public bibliographic APIs work, preserve their exact requests and returned records; inaccessible services go in the failure log.

Eligibility: a source must inform a required representation, planner, predictor, uncertainty model, calibration/evaluation method, benchmark, or limiting theorem. Exclude quantum-keyword-only papers, unrelated applications, unverified metadata, duplicate versions as separate studies, and snippets without an opened source. Preprints remain explicitly preprints unless an official venue record verifies publication. Metadata-only records cannot support detailed technical claims. Avoid cross-paper numerical rankings without compatible protocols.

Search families: (1) hidden quantum Markov / observable operator / predictive state / density matrix sequence; (2) locally purified tensor network / belief propagation / ensemble decomposition / quantum trajectories; (3) world model / object centric / diffusion / particle filtering / trajectory prediction; (4) robot dynamic obstacle planning / chance-constrained MPC / CVaR / belief space / active perception / social navigation; (5) random finite set tracking / calibration; (6) simulator, robot and venue official documents. Use exact-title verification and citation chaining following discovery. Save exact strings and dates per query.

Extraction: stable ID, full author list when verified, title, year, venue/status, DOI/arXiv/URL, source and exact section/page, contribution, representation, planner, uncertainty, benchmark, metrics, result scope, limitations, component relevance, support/weakening, code/license status. Unknown fields remain UNKNOWN; not all papers evaluate robots. A theorem is not empirical evidence of navigation benefit.

Screening: deduplicate DOI/arXiv and normalized title; link journal/preprint reports; assign INCLUDE, BACKGROUND, NOT_RETRIEVED, UNVERIFIED or EXCLUDE with reason. Team domain extraction is followed by coordinator consistency checks; disclose that this does not satisfy independent human double screening. Count explicit candidate records/reports only. Maintain unavailable records separately. No meta-analysis is planned because tasks and outcomes differ.

Quality appraisal: inspect formal assumptions, actual method, evaluation setting, classical comparators, resource controls, seeds/uncertainty if reported, reproducibility, and external validity. Do not invent a GRADE rating for algorithm papers. Source-supported facts use [ESTABLISHED]; own deductions [INFERENCE]; proposals [HYPOTHESIS]; unmeasured uncertainty [UNKNOWN]. [OBSERVED] is reserved for saved executed project outputs.

Synthesis sequence: evidence -> novelty boundary -> hypotheses/nulls -> Stage 0 protocols -> engineering recommendation -> robotics/publication program. No full model or simulator implementation before Stage 0. Decisions will not be relabeled completed experiments. Novelty claims are bounded to retrieved evidence.
