# Risk register

All likelihood/severity judgments are qualitative project inferences, not estimated frequencies. Owner roles are proposed assignments, not named people. Review at every gate.

| Risk | Severity | Detection / trigger | Mitigation and stop rule | Owner |
|---|---|---|---|---|
| QLC overlaps HQMM/OOM | High | Source/model correspondence | Position as constrained sequence baseline; require additional algorithm/empirical contribution | Theory |
| PSC overlaps classical tensor/graph prediction | High | Joint models match curves | Include joint/nonnegative tensor rivals; stop claimed purification novelty | Representation |
| TEC identity is redundant/gauge | High | Equal-rho common-instrument equality; real particles match | Exact equivalence tests; defer TEC if no extra useful state principle | Theory |
| Apparent gain is hidden context/decoder capacity | High | Unmatched weights/state/history | Count all memory and trainable parts; constrain decoder contract | Evaluation |
| Forbidden-mass metric rewards mode collapse | High | Missing valid modes | Co-require TV/proper score and valid-mode coverage | Evaluation |
| Rank/order sensitivity | High | Long-range or permuted graph loses dependence | Sweep order/topology; explicit graph cost; stop scaling if frontier fails | Tensor methods |
| Truncation drops rare catastrophe | High | Small norm error but high decision loss | Cost-aware validation and rare-mode tests; no certificate from weight alone | Safety/model |
| BP nonconvergence or invalid messages | High | Residual/divergence, exact-small mismatch | Damping, iteration cap, exact/tree or conservative fallback; count fallback latency | Inference |
| Slot identity/existence failure | High | ID switches, false births/deaths, overflow | Shared tracker, RFS/multi-hypothesis baseline, absent state and overflow policy | Perception |
| Synthetic simulator bias | High | Only training policy/geometry succeeds | External replay plus reactive policies; map/policy holdouts; transfer validation | Robotics |
| Uncalibrated risk under shift | High | Reliability/coverage deterioration | Separate calibration set; OOD/abstention; independent safety monitor | Evaluation |
| Latency deadline misses | High | p99 latency or jitter budget fails | End-to-end profiling; bounded computation/fallback; no average-only claim | Systems |
| Compute/confounded planner causes gain | High | Improvement disappears with common planner/budget | Crossed attribution blocks and oracle planner comparisons | Experiments |
| Pseudoreplication/selection bias | High | Frame-level n; selected seeds; successful-only reporting | Map/model clustering, held-out selection, raw assigned episodes | Statistics |
| Underpowered rare-event study | High | Wide collision-risk interval | Pilot nuisance ranges, simulate exact analysis, expand independent clusters | Statistics |
| Software/version/license mismatch | Medium–high | Broken ROS/simulator combo or unclear assets | Pin compatible versions; smoke test; audit each dependency/asset | Reproducibility |
| Hardware/sensor access unavailable | Medium | No suitable calibrated platform | Simulation-first; no assumed purchase; revise scope transparently | Robotics |
| Real-robot incident | High | Stopping distance/monitor failure | Stop trial, preserve logs, review before restart; controlled progression | Safety lead |
| Literature omission/status error | High | New prior art/metadata conflict | Primary-source ledger, rerun targeted search before submission, retract unsupported claim | Literature |
| Conflicting venue webpage/cache | Medium | Stale search snippet versus opened policy | Prefer dated opened instructions; retain conflict and recheck pre-submission | Publication |
| Overlapping submission | High | Same result under simultaneous review | One archival submission at a time unless explicit policy permits exception | Corresponding author |

No human-participant testing, purchases, account changes, external submissions or paid research API calls were performed in producing this package.
